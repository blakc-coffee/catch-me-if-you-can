## Files to Delete

1. **`catch-me-if-you-can/package-lock.json`**
   - **Reason**: Orphaned root lockfile (104 bytes containing `{ "packages": {} }`). There is no root `package.json` in `catch-me-if-you-can`; backend dependencies live in `backend/` and mobile app dependencies live in `openverse-native/`.
   - **Action**: Deleted.

2. **`catch-me-if-you-can/google-services.json`**
   - **Reason**: Deprecated Google Services configuration file hardcoded to an abandoned legacy project (`seekerdb-9e679`). The active configuration used by Android builds and Expo config plugin is located at `openverse-native/google-services.json` (configured for production project `cmiyc-d170c`).
   - **Action**: Deleted.

3. **`catch-me-if-you-can/backend/firestore-debug.log`**
   - **Reason**: Stale, empty 0-byte debug log file left over from local emulator sessions.
   - **Action**: Deleted.

4. **`catch-me-if-you-can/backend/firebase-debug.log`**
   - **Reason**: Stale debug output log generated by historical Firebase CLI executions.
   - **Action**: Deleted.

## Functions/Methods to Delete

### `catch-me-if-you-can/backend/functions/src/lib/errors.ts`
- **`reasonOf(err: unknown): ErrorReason | undefined`**
  - **Reason**: Exported utility intended to inspect `HttpsError.details.reason`. It is never called anywhere across `backend/functions` or test suites (`openverse-native` implements its own client-side `getCallableReason` helper).
  - **Action**: Deleted.

### `catch-me-if-you-can/openverse-native/src/services/session/localStore.ts`
- **`ScopedStore.prototype.clearActiveScope(): Promise<void>`**
  - **Reason**: Unused method on the `ScopedStore` class. Active scopes are updated via `activate()`, `stopCollecting()`, or cleared conditionally through `purgeExcept()`. `clearActiveScope()` is never called anywhere in application code or tests.
  - **Action**: Deleted.

### `catch-me-if-you-can/openverse-native/src/services/session/localStore.ts`
- **`export { initialGameState }`**
  - **Reason**: Redundant re-export of `initialGameState`. All consumers (`App.tsx`, `gameState.test.ts`) import `initialGameState` directly from `src/services/session/gameState.ts`.
  - **Action**: Deleted re-export.

### `catch-me-if-you-can/openverse-native/src/services/backgroundLocationTask.ts`
- **`export { LOCATION_TASK_NAME }`**
  - **Reason**: Unused re-export. `backgroundLocationTask.ts` is imported purely for side effects (`import "./src/services/backgroundLocationTask"`) in `index.ts`. All consumers of `LOCATION_TASK_NAME` import it directly from `src/services/locationService.ts`.
  - **Action**: Deleted re-export.

## Variables/Constants to Delete

### `catch-me-if-you-can/backend/functions/src/config.ts`
- **`LIMITS.telemetryMaxAgeMs`**
  - **Reason**: Unreferenced configuration property in the `LIMITS` dictionary (`10 * 60 * 1000`). Live telemetry freshness enforcement exclusively uses `TELEMETRY_LIMITS.maxFixAgeMs` in `plausibility.ts`.
  - **Action**: Deleted.

### `catch-me-if-you-can/openverse-native/src/services/firebase/config.ts`
- **`export const firebaseEmulatorHost`**
  - **Reason**: Leaked export. The emulator host string is only referenced internally in `config.ts` (lines 42–44) and is never imported by any external module.
  - **Action**: Removed `export` modifier, converted to private module constant.

### `catch-me-if-you-can/openverse-native/src/services/session/sessionRuntime.ts`
- **`export const sessionDeps`**
  - **Reason**: Leaked export. `sessionDeps` is only used internally within `sessionRuntime.ts` to wire up session functions (`handleAuthChange`, `startTracking`, etc.) and is never imported externally.
  - **Action**: Removed `export` modifier, converted to private module constant.

### `catch-me-if-you-can/openverse-native/src/services/firebase/directFirestore.ts`
- **`export const FALLBACK_PUZZLES`**
  - **Reason**: Leaked export and bundled anti-cheat violation. Unused outside of `directFirestore.ts`, and contained static answers/clues that tripped the `noBundledAnswers.test.ts` anti-cheat audit.
  - **Action**: Removed `export` modifier, scrubbed bundled clues and answers to satisfy anti-cheat validation.
