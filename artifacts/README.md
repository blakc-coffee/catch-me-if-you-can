# Game artifacts (printable QR codes)

Generated by `backend/functions/scripts/generateArtifactQr.ts` (or copied from seed output).

| File | Purpose |
|------|---------|
| `qr-codes/artifact-qr-codes.csv` | Spreadsheet for organisers |
| `qr-codes/artifact-qr-codes.json` | Machine-readable manifest |
| `qr-codes/png/*.png` | Printable QR images (15 correct artifacts) |

**Scan payload:** the `qrCode` value (e.g. `OV-seed-a01-…`). Register in Firestore via `npm run seed` in `backend/`.

Regenerate:

```bash
cd backend/functions && npm run generate:qr
cp -r seed-output/artifacts/* ../../artifacts/qr-codes/
```
